# v2.0.7

## Estimated energy tracking for flex / flat

flex/flat units now get **energy sensors** — per level and a combined total — suitable for the HA Energy Dashboard.

Unlike touch units, flex/flat don't report per-level operating hours over Modbus, so the integration counts the time spent at each fan level itself (poll-based) and multiplies by the per-level watt values. The sensors are `TOTAL_INCREASING` and persist across restarts.

Because this is a **poll-based estimate, not a measurement** (level changes between two polls are attributed to the last-seen level), the sensors are clearly named "(estimated)", kept separate from the measured touch sensors, and disabled by default — enable them from the entity registry if you want them.

## 130 flat validated on real hardware

Thanks to **@agmorpheus**, the profi-air 130 flat is now confirmed on real hardware:

- **Register map matches the flex models** — a full register dump confirmed temperatures, fan RPM, filter, bypass, mode and reference RPM all read correctly. The documentation-based implementation holds.
- **Measured watt values shipped** (16 / 21 / 33 / 44 W per level) — so both the live power attribute on the fan entity and the new estimated energy sensors work out of the box on the 130 flat.
- **Room temperature (T5) fix** — the 130 flat has no room sensor and returns a placeholder 88 °C; this is now shown as unavailable instead of a fake reading.
