# v2.2.0

## New (experimental): profi-air 140 / 200 lite

A third protocol family next to touch (HTTP/XML) and flex/flat (Modbus): the Wi-Fi module of the lite units speaks REST/JSON.

> **Experimental:** derived from the manufacturer app and not yet confirmed on a real lite unit. Feedback and the diagnostics download are welcome.

- **Local only.** No cloud, no credentials, and no fallback to the cloud. If the device rejects a command, an error is shown.
- **Automatic detection** in the config flow.
- **Entities:**
  - Ventilation with on/off and presets Auto, Night, Minimum, Maximum
  - Room temperature, humidity, air quality (level 1–5)
  - Alarms and window contact
  - Key lock (switch)
  - Optional register temperature
  - Setpoint and winter/summer mode exist but are disabled by default (per the app they only apply with a hydronic battery)
- **Not available** through this interface: air volume, fan speed, filter, bypass, energy.
- **Deliberately not implemented:** commands that write device registers or network settings.
- Password fields are masked in the diagnostics download.
- Docs: `docs/lite-rest.md`

## flex/flat: alignment with the manufacturer app

All existing offsets and encodings match the app. The points below are **not yet confirmed on hardware**; the changes keep the previous behaviour if a device does not support them.

- **Operating mode:** Night and Fireplace are recognised with both known numberings (app: 16/9, docs: 7/12). Register 168 resolves conflicts. Further states (standby, servoflow, fault mode …) show as plain text instead of "Mode N".
- **Alarms** are also read from the bitmask (register 170). "Alarm active" honours it and the alarm text lists all simultaneous alarms.
- **Acknowledge alarm** writes the alarm code to register 514 like the app (previously 0).
- **Summer** additionally writes register 476. A rejected write is non-fatal.
- Registers 168–171 are read fault-tolerantly; after three failures the block is skipped.
- Docs: `docs/flex-modbus.md`, section "Erkenntnisse aus der Hersteller-App"
