# v2.2.1

Follow-up to the HACS default-repository review.

## Changed: device clock sync is now opt-in (off by default)

Previously the integration wrote the time to the device at every setup and every 24 h (touch: `POST /time.htm`, flex/flat: register 40111) — also without installer credentials, and without being documented.

- New option **"Set device clock from Home Assistant"** (Settings → Configure, touch and flex/flat). **Off by default**: nothing is written and no timer is scheduled.
- **Upgrade note:** if you relied on the automatic clock sync (since v2.1.1), enable the option once.
- The README documents the option and exactly what it writes.

## Fixed: wording of the touch "read-only" mode

Skipping the installer credentials is **not** a read-only mode. Fan level, party timer, bypass mode and bypass thresholds still write to the device via `stufe.cgi` / `setup.htm` (no login needed). Only the installer area (`install.htm`) stays locked. README, config flow menu and translations (de/en) now say so.

## Fixed: release zip contained bytecode

- `ha-profiair.zip` contained `__pycache__/*.pyc` files from the workflow's test run. The workflow no longer lets the test run write bytecode, excludes `__pycache__`/`*.pyc` when packaging, and fails if any ends up in the zip.
- 42 accidentally committed `__pycache__` files (from the v2.2.0 release commit) are removed from the repository; `.gitignore` added.
- 21 new tests (`tests/test_phase16_hacs_review.py`).
